# External Plugin Post-Request (ext-plugin-post-req)

> This document contains information about the Apache APISIX ext-plugin-post-req Plugin.

Source: https://apisix.apache.org/docs/apisix/plugins/ext-plugin-post-req/

## Description

`ext-plugin-post-req` differs from the [ext-plugin-pre-req](/docs/apisix/plugins/ext-plugin-pre-req/) Plugin in that it runs after executing the built-in Lua Plugins and before proxying to the Upstream.

You can learn more about the configuration from the [ext-plugin-pre-req](/docs/apisix/plugins/ext-plugin-pre-req/) Plugin document.
